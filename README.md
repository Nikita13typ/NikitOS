# НикитОС 3.0

**НикитОС** — экспериментальная веб-операционная система в одном HTML-файле. Работает в браузере на компьютере, планшете и телефоне.

🌐 **Запустить:** https://nikita13typ.github.io/NikitOS/

## Возможности

- Рабочий стол с панелью обзора и быстрыми действиями.
- Меню «Пуск» с поиском приложений.
- Окна приложений: перемещение, сворачивание, закрытие и разворачивание.
- Центр системы с быстрыми переходами и горячими клавишами.
- Файловый менеджер с виртуальными папками и текстовыми файлами.
- Заметки с автосохранением.
- Планировщик задач.
- Калькулятор, часы и быстрые настройки.
- НикитМаркет с каталогом мини-приложений.
- Светлая, ночная и закатная темы.
- Резервное копирование и восстановление данных в JSON.
- Адаптация для Android и компьютеров.

## Запуск локально

Скачай `index.html` и открой его в современном браузере. Установка не требуется.

## Данные и приватность

НикитОС не требует регистрации. Основные данные сохраняются локально в хранилище браузера на устройстве. Для переноса данных используй раздел «Настройки → Резервная копия».

## Горячие клавиши

- `Ctrl + K` — меню «Пуск».
- `Esc` — закрыть панели.
- `Ctrl + Shift + O` — центр системы.
- `Ctrl + Shift + F` — полный экран.

## Технологии

HTML, CSS и JavaScript. Внешние библиотеки не требуются.
