# НикитОС

**НикитОС** — экспериментальная веб-операционная система в одном HTML-файле. Она запускается прямо в браузере и подходит для компьютеров, планшетов и телефонов.

## Возможности

- Рабочий стол и меню «Пуск».
- Окна и демонстрационные приложения.
- Заметки с сохранением в `localStorage` браузера.
- Калькулятор.
- Быстрые ссылки браузера.
- Поиск приложений.
- Настройки и выбор обоев.
- Часы и дата.
- Адаптация интерфейса под мобильные экраны.

## Запуск

Скачайте `index.html` и откройте его в современном браузере.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Сайт появится по адресу `https://Nikita13typ.github.io/NikitOS/`.

## Хранение данных

Заметки сохраняются локально в браузере с помощью `localStorage`. Они не синхронизируются между устройствами и браузерами. Очистка данных сайта может удалить сохранённые заметки.
